# Learn about YAML
- What is YAML ?
   - `Ans:` YAML stands for "YAML Ain't Markup Language" (originally "Yet Another Markup Language"). It is a human-readable data serialization format used to store configuration, settings, and structured data.
- Why need to learn YAML ?
   - `Ans:` YAML is extremely popular in DevOps tools example - Docker Compose, Kubernetes, Github Actions, CI/CD Pipelines, Application Configuration Many applications store settings in YAML (Ansible, Prometheus), Configuration Many frameworks use YAML because it is easier for humans to edit than JSON (symphony, spring boot)
- Why use YAML if JSON already exists?
   - `Ans:` Easier for Humans, The YAML version is cleaner and easier to edit manually, supports comments but JSON ar'nt support comments, that's are very usefull features , Better for Large Configurations - A large Kubernetes deployment may be hundreds of lines long, when you try to configure in JSON version becomes difficult to maintain . Multi-line Strings YAML handles long text naturally . Advanced Features (Anchors, Aliases, References)
