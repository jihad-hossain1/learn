- running container see  
```bash 
docker ps
```

- show hidden/previous run or all container records show
```bash
docker ps -a
```

- see docker all images list
```bash 
docker images
```

- remove image from docker
```bash
docker rmi -f <image name/id>
```

- docker pull an new images an run it
```bash
docker pull <image name write here> 
```

- run a new container
```bash
docker run -it <image name/id>
```

- rename a container name
```bash
docker run --name <name of container> -it <image name>
```
